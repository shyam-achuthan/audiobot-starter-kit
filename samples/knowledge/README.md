# Sample knowledge pack (fictional)

Demo content for a fictional product, **QuickBill**, billing and inventory software for Indian shops,
sold by "AudioBots Demo". Upload these files on the admin **Knowledge** page to try the agents.

- `quickbill-pricing.md`: plans, prices, discounts, trial
- `quickbill-policies.docx`: refunds, cancellation, data and support hours (Word)
- `quickbill-troubleshooting.pdf`: common problems and fixes (PDF)

All names, prices and policies here are made up.
